# 课程指南

本次培训以 `Assets/Training/Scenes/03_FanTraining.unity` 为主讲场景：一个风扇模型、四片可旋转扇叶、风扇开关与巡检两个 uGUI 按钮，由 FanTrainingController 控制。

完整教材为 [Unity风扇与巡检培训手册.md](Unity风扇与巡检培训手册.md)，另提供同名 Word 和 HTML 版。

| 天 | 核心课程 | 操作结果 |
|---|---|---|
| 1 | 编辑器和包下载安装、基础操作、风扇模型和 Prefab | 模型层级与转轴正确 |
| 2 | Animation 关键帧、Animator 参数与过渡、uGUI 与脚本 | 按钮能启停循环扇叶 |
| 3 | Cinemachine 四面巡检、按钮脚本、Timeline 对照 | Instructions/Hold/Blend/Loop、开始停止与正面重播，再练 Timeline 暂停继续 |
| 4 | C#、机房多点巡检、设备交互、HTTP | 真实查询控制和提交，失败保留重试 |
| 5 | Inspector、EditorWindow、Handles、Undo、构建与考核 | 工具可定位、可撤销、可保存 |

安装版本：Unity 2022.3.55f1c1、Cinemachine 2.9.7、Timeline 1.6.2。Animation 和 Animator 为内置功能，无需单独下载。安装步骤、手动复现、预期结果和排错见完整教材第 3～11 章。

三天压缩版及零编程基础建议见完整教材第 2 章；原机房细化教案保存在 [机房培训补充.md](机房培训补充.md)。

四面巡检的详细配置、字段对应表、按钮接线、脚本分支和验收步骤，见完整教材第 10.1～10.12 节，或独立的 [巡检按钮接线说明.md](巡检按钮接线说明.md)。当前场景 Loop 已开启。
